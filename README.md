# Wolfgang

A PHP MVC framework inadvertently developed by Ramone Burrell.

--------------------------------------------------------------------


To create an application from the framework, first set the execute bit on the file cli.php:

`chmod +x cli.php`

then, execute the script as below:

`./cli.php --create-project --name "My App" --short-name myapp --overwrite --dest /var/www/myapp/ --root-domain myapp.com`

Once you add myapp.com to your hosts file and you have configured a virtualhost, navigate to https://myapp.com.
